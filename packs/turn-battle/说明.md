# 回合战斗规则包(turn-battle 1.0)

Inkwright 的第一方规则系统包,原创规则。三人小队(骑士、法师、牧师)对一群敌人,按速度轮流出手,像老式日式角色扮演游戏的战斗。

## 用法

在游戏笔记(`game.md`)里写:

```yaml
system: { path: <到这个文件夹的相对路径>, version: 1 }
```

然后在故事里叫出敌人,开打:

```ink
INCLUDE _engine.ink
~ spawn("foe", "goblin")
~ spawn("foe", "orc")
~ spawn("foe", "shaman")
-> battle ->
{ battle_result == "won":
    赢了,打了 {battle_round} 回合。
- else:
    全倒下了。
}
```

运行「生成游戏引擎 ink」后,生成的 `_engine.ink` 会 INCLUDE 这里的 `rules.ink`。`template/` 是一个能直接玩的例子(山道上的 3 对 3),「新建游戏」就是复制它。一个故事里可以打好几场:每场之前 `spawn` 新的敌人,再 `-> battle ->`;小队的生命、法力、药水和中毒都会带到下一场。

## 包里有什么

- `system.md`:规则、三名队员、敌人种类 `foe` 的五个模板(地精、兽人、萨满、灰狼、巨魔)、药水(资源)、三种状态(中毒、眩晕、防御)。
- `rules.ink`:流程。入口 `-> battle ->`;结束后 `battle_result` 是 `"won"` 或 `"lost"`,`battle_round` 是打了几回合。

## 规则

- **回合**:每回合所有站着的人各行动一次,速度(`spd`)高的先动;速度相同时队员先动。回合结束时中毒的人 -2 生命,然后各种状态的回合数减一。
- **伤害**:攻击 + 2d6 − 4 − 对方防御,至少 1;2d6 掷出 11 或 12 是暴击,再 +2。
- **队员的行动**(轮到谁,就给谁的选项):
  - 攻击任意一个敌人。
  - 技能(`art`,花法力):骑士**盾击**(2 法力,打一下并让对方眩晕,跳过它的下一次行动);法师**火球**(3 法力,每个敌人 2d6−3,至少 1,无视防御);牧师**治疗**(2 法力,一名队员 +2d6 并解毒)。
  - **防御**:防御 +3,直到自己下一次行动。
  - **药水**:伤得最重的人 +6(全队共用,开局 2 瓶)。
- **敌人的行动**:扑向随机一名站着的队员;`venom` 为 1 的敌人(萨满)先给还没中毒的人下毒(3 回合)。
- 生命到 0:队员倒下(身上的状态清掉),敌人消失。

## 改它

游戏笔记里写同 id 的条目就会替换包里的:换一支小队写 `party:`(每名队员要有 `hp`、`hp_max`、`mp`、`mp_max`、`atk`、`def`、`spd`、`art`、`acted`;`art` 1/2/3 决定技能。**`art` 必须是 1、2 或 3**:规则靠它分辨谁是队员,写成 0 或不写的队员会像敌人一样自动行动、倒下时直接消失),改敌人写同 id 的 `foe` 种类(整个种类替换)。包的 `system.md` 不用动。要改流程,把 `rules.ink` 里的段落复制到自己的故事里改名再用。

## 平衡(2026-11-10)

例子里的山道一战(地精、兽人、萨满),各打 500 局:

- 按固定策略打,胜 88%,平均 4.7 回合,赢的时候平均 2.5 人站着。策略是:有人生命低于四成就治疗,低到 5 以下喝药水;法师有法力就放火球;骑士有法力就盾击兽人;其余攻击生命最少的敌人。
- 每一步都随便选,胜 17%。
