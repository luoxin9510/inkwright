# 地城爬行规则包(dungeon-crawl 1.0)

Inkwright 的第一方规则系统包,原创规则。四人小队一间一间往地城深处走,最深处是深渊督军。

## 用法

在游戏笔记(`game.md`)里写:

```yaml
system: { path: <到这个文件夹的相对路径>, version: 1 }
```

然后在故事里:

```ink
INCLUDE _engine.ink
~ crawl_rooms = 6        // 可选,默认 6 间
-> crawl ->
{ crawl_result:
- "won":    督军倒下了。
- "left":   回到了地面。
- else:     没有人回来。
}
```

运行「生成游戏引擎 ink」后,生成的 `_engine.ink` 会 INCLUDE 这里的 `rules.ink`。`template/` 是一个能直接玩的例子,「新建游戏」就是复制它。

## 包里有什么

- `system.md`:规则(2d6)、四名队员(剑手、弓手、盾卫、学者)、敌人种类 `foe` 的八个模板、三张表(房间、浅层怪物、深层怪物)、火把/药水/金币。
- `rules.ink`:流程。入口 `-> crawl ->`;结束后 `crawl_result` 是 `"won"`、`"left"` 或 `"fallen"`,`depth` 是走到第几间。

## 规则

- **房间**:每进一间烧一支火把;没有火把时随机一人摔一跤(-1 生命)。掷房间表:空屋、怪物、宝箱(2d6 × 深度 枚金币)、陷阱、祭坛(站着的人各 +2 生命)。最后一间是督军。
- **怪物**:前一半房间掷浅层表,后一半掷深层表。
- **战斗**:每轮选一名站着的队员攻击生命最少的敌人:2d6 + 力气 ≥ 7 + 敌人护甲 就打中(-1),超出 3 点以上 -2。然后每个敌人攻击随机一名站着的队员:2d6 + 攻击 ≥ 7 + 队员护甲,同样 -1 / -2。也可以喝药水(伤得最重的人 +3,不超过上限)或逃跑(敌人再打一轮,然后离开这间屋子;从督军面前逃跑算回头)。
- **陷阱**:随机一人 2d6 + 力气 ≥ 8 躲开,否则 -2。
- 每走完一间可以选择回头。

## 改它

游戏笔记里写同 id 的条目就会替换包里的:换一支队伍写 `party:`,改某个怪物写同 id 的 `foe` 种类(整个种类替换),加一张表写新的 `tables:` 条目。包的 `system.md` 不用动。要改流程,把 `rules.ink` 里的段落复制到自己的故事里改名再用。
