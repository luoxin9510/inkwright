# 叙事检定规则包(narrative-check 1.0)

Inkwright 的第一方规则系统包,从宿舍恐怖游戏《302》的规则里整理出来。适合以剧情为主的游戏:没有战斗流程,只有选项上的检定、技能变成的内心声音、两条血条和同伴关系。

## 用法

在游戏笔记(`game.md`)里写包的路径,再写自己的角色:

```yaml
system: { path: <到这个文件夹的相对路径>, version: 1 }
characters:
  - { id: me, name: { zh: 我, en: Me }, skills: { reason: 3, stamina: 3, charm: 3, insight: 4, strength: 2 } }
  - { id: lin, playable: false, name: { zh: 林, en: Lin }, skills: { reason: 4, stamina: 2, charm: 3, insight: 3, strength: 2 }, companion: { fear: 30, trust: 50 } }
```

故事里:

```ink
INCLUDE _engine.ink
* [贴着门听 #check:insight:normal]
    { check("insight", 10) >= 3:
        听清了。
    - else:
        什么也没听清。
        ~ fear += 30
    }
别出声。 #voice:reason
~ trust_lin = clamp(trust_lin + 10, 0, 100)
```

运行「生成游戏引擎 ink」后,生成的 `_engine.ink` 会 INCLUDE 这里的 `rules.ink`。`template/` 是一个能直接玩的例子(半夜的敲门声),「新建游戏」就是复制它。

## 包里有什么

- `system.md`:
  - 规则:2d6 + 技能 ≥ 难度。难度有六档:trivial 6、easy 8、normal 10、hard 12、severe 14、legendary 16。
  - 五种技能,每种都有自己的声音和颜色:理智、耐力、魅力、洞察力、力量。
  - 两种资源:恐惧 0–100、体力 0–10。
  - 同伴的两种资源:恐惧(默认 20)、信任(默认 50)。每个同伴都有自己的一份,比如 `fear_lin`、`trust_lin`。
  - 一条修正:恐惧每满 25,理智检定 −1。
- `rules.ink`:`clamp(x, lo, hi)`,把一个数限制在区间里。改同伴的恐惧和信任时用得上,因为引擎只在一步结束后才把资源拉回范围。

## 规则

- **检定**:选项上写 `#check:<技能>:<难度>`,玩家在按钮上就能看到成功率。故事里用 `check("技能", 数字)` 读结果,得到 0–4 档,3 及以上算成功。失败也必须改变点什么,比如一个变量或者之后能选的选项;`check-ink --all` 会对什么都没改变的失败给出警告。
- **声音**:一行字带 `#voice:<技能>`,就会以那个技能的口吻、颜色显示。
- **恐惧**:心理的血条。恐惧越高,理智越差。
- **体力**:身体的血条。
- **同伴**:`playable: false` 的角色不能选来玩,但有自己的恐惧和信任。

## 改它

在游戏笔记里写一个同 id 的条目,就会替换包里的那一条。比如:

- 换一个技能的声音:写同 id 的 `skills:` 条目。
- 加一种资源:写在 `resources:` 里,比如《302》的电量和"天亮前"。
- 不要恐惧修正:写 `modifiers: []`。

包的 `system.md` 不用动。

## 谁在用

《302》(dorm-302):它的 `game.md` 只写自己的电量、天亮前、角色和物品,其余都来自这个包的一份副本。换成这个包以后,`check-ink --all` 两种语言的结果和换之前一样。
